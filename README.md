# TrailInfo

Catálogo de 18 senderos de El Paso, Texas, con un índice de dificultad de 0 a 100
por ruta. Dos formas de consultarlo: buscador con autocompletado y filtros, o
mapa interactivo con cada ruta coloreada por nivel.

El índice combina desnivel, terreno, distancia, exposición y autonomía con pesos
fijos, y la ficha de cada ruta muestra la operación completa.

Next.js 15 · React 19 · Tailwind CSS 4 · Leaflet

```
npm install
npm run dev
```

Detalles del modelo en [docs/planning.md](docs/planning.md) y de la
implementación en [docs/project.md](docs/project.md).
